# design-doc

An OpenCode skill for writing effective software design documents, based on [Refactoring English](https://refactoringenglish.com/excerpts/write-an-effective-design-doc/).

Covers when to write a design doc, what belongs in one, all 18 standard components, and common mistakes to avoid.

## Install

```bash
opencode skill add coker-felix/design-doc-skill
```
